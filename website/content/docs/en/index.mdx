`pmoke` coordinates instrument communication, waveform acquisition, lock-in processing, phase rotation, and Kerr-angle calculation.

## Pipeline

1. Acquire oscilloscope channels and metadata.
2. Fit the optical reference signal.
3. Integrate sensor channels.
4. Demodulate signals with the configured lock-in filter.
5. Rotate phase and calculate the Kerr response.

## Design priorities

- Reproducible `config.toml` inputs
- Explicit hardware transport diagnostics
- Bounded, testable analysis stages
- A keyboard-driven terminal monitor

ネイティブ pmoke と同一の Rust カーネルを専用 Web Worker 内で実行するアナライザー。合成信号とローカル CSV のブラウザ内保持。完全な解析入力と独立した表示用間引き。全入力から生成される出力値。

<WaveformAnalyzer locale="ja" />

## 可視解析

入力波形、lock-in X/Y、振幅・位相、Kerr 角、filter response の四つの同期 plot。
sample rate、reference frequency、noise、boxcar half-window、stride、位相回転、
高調波、Kerr factor の control。browser 内で完結する local CSV 解析と metadata 付き CSV export。

## 一致範囲

M4 のネイティブ等価対象となる `boxcar_legacy`、位相回転、高調波 Kerr 計算。ブラウザ一致対象外となる FIR フィルター、`sync_iir_zero_phase`、位相フィッティング、標準 Kerr。これらの本番解析に必要なネイティブ pmoke。

`time,signal` または信号単列に対応する CSV 入力。有限・単調増加・等間隔が必須となる時間列。信号単列で使用するサンプルレート制御。16 MiB、入力 1,000,000 点、高調波出力合計 1,500,000 点の固定上限。

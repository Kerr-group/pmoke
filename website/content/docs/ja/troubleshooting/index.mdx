## 診断からの開始

```bash
pmoke --config config.toml doctor
pmoke --config config.toml doctor --json > doctor.json
```

build feature、controller、装置address、storage access、Python import、設定診断を分けたreport。

## 装置応答なし

1. `doctor`出力にあるnormalized URIと必要featureの比較。
2. `pmoke instruments explain MODEL`によるmodel対応transportの確認。
3. `pmoke instruments query`によるSCPI装置への明示query。
4. Prologix adapterへの到達性と装置のPAD failureの切り分け。
5. cableとcommand terminator確認後のURI timeout延長。

## artifact 拒否

- 変換・解析前の`pmoke raw verify`。
- すべての参照波形と`acquisition/manifest.toml`の一体保存。
- stale-stage診断が示すupstream stageの再実行。
- 取得設定変更時の新しい`--run-dir`。
- 最終publish済み解析の保持とincomplete tree内のfailed run確認。

## Lock-in warning

表示上のnoiseではなく、Nyquist、excessive gain、ill-conditioned integer-period coefficient、settling range warningなどの数値診断を確認。smoothingを増やす前に安定したfilterとoutput strideを選択。

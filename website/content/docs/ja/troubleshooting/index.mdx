## 診断からの開始

```bash
pmoke --config config.toml doctor
pmoke --config config.toml doctor --json > doctor.json
```

build feature、controller、装置 address、storage access、Python import、設定診断を分離した report。

## 装置応答なし

1. `doctor` 出力にある normalized URI と必要 feature の比較。
2. `pmoke instruments explain MODEL` による model 対応 transport の確認。
3. `pmoke instruments query` による SCPI 装置への明示 query。
4. Prologix adapter 到達性と装置 PAD failure の切り分け。
5. cable・command terminator 確認後のみの URI timeout 延長。

## artifact 拒否

- 変換・解析前の `pmoke raw verify`。
- 全参照波形と `acquisition/manifest.toml` の一体保存。
- stale-stage 診断が示す upstream stage の再実行。
- 取得設定変更時の新規 `--run-dir`。
- 最終 publish 済み解析の保持と incomplete tree 内の failed run。

## Lock-in warning

表示上の noise ではなく数値診断となる Nyquist、excessive gain、ill-conditioned integer-period coefficient、settling range warning。smoothing 増加前の安定 filter と output stride の選択。

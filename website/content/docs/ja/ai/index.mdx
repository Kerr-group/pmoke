## 取得順序

1. 探索の起点となる[`llms.txt`](https://kerr-group.github.io/pmoke/llms.txt)。
2. 選択したlocaleに対応する関連pageのMarkdown URL。
3. 正確なcommand、option、field、default値を確認する生成JSON契約。
4. 複数pageにまたがるtaskでのみ使用するlocale別context feed。
5. 言語横断のcontextが必要な場合に限って使用する日英統合feed。

## 権限境界

このdocumentationはworkstationや測定装置の状態を観測しない。config semanticsの最終基準は
`pmoke config validate`、compiled featureとlive hardwareの最終基準は
`pmoke doctor hardware`。credential、address、driver availability、instrument stateの推測禁止。

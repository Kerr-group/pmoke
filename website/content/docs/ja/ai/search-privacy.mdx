## ローカル検索

deterministicな`pmoke-domain-v1` bilingual concept projectionを使う検索。
日英domain synonymの共通concept dimensionと、正確なcommand・config pathを保持する
bounded hashed lexical featureを使用。semantic moduleを遅延読み込みした後、browser内でstatic recordを
rankingするOrama OSSを利用。

neural embedding service、生成回答engine、cloud検索productではなくconcept-vector検索。

## Data境界

- index対象は公開documentationのみ。
- GitHub Pagesから同一originのstatic indexを配信。
- query upload、analytics、cookie、account、telemetryは不使用。
- local config、CSV input、instrument address、browser tool stateはindex化しない。
- service workerなしで完全offlineに対応することは非主張。

## Failure境界

Orama、concept index、hybrid moduleの読み込みに失敗しても、locale限定のZBSearch全文検索を利用可能。
navigationを妨げず、日英indexを混在させない**全文検索フォールバック**を表示。

## 品質Gate

localeごとに40 query以上のversioned relevance fixtureを用意。各localeのRecall@5は0.85以上、
cross-locale leakageなし、warm p95は100 ms未満、readinessは1秒未満。
これらと明示的なstatic asset budgetをCI gateで要求。

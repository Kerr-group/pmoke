過去の実験設定を複製せず、実行中binaryが提供する現行templateを起点に設定:

```bash
pmoke config init --output config.toml
```

## 装置 endpoint

オシロスコープとのdirect接続を`scope`に定義。trigger sourceと、direct GPIBまたはPrologix adapterを`generator`に定義。

```toml
version = 5

[scope]
model = "DHO5108"
connection = "tcp://192.0.2.10:55255"

[generator]
model = "WF1946B"
connection = "prologix-tcp://192.0.2.20:1234?addr=11"
```

## channel role

各sensorにはscale形式を一つだけ指定。周波数・位相推定の基準となるreference channelと、光学応答を含むlock-in signal channelを設定。

```toml
[[sensors]]
channel = 1
scale = { max_abs = 55.0, polarity = -1 }
label = '$\mu_0H$'
unit = "T"

[reference]
channel = 2
fft_window = { start = 0.0, end = 0.015 }

[lockin]
signal_channels = [3]
filter = { kind = "boxcar_legacy", half_window_cycles = 1.0 }
```

## artifact 方針

大容量DHO captureにはRAW取得を使用。shotごとの分離と不変な設定snapshotには`--run-dir`を使用。

```toml
[data]
output = "raw"
input = "auto"
screenshot = true
```

すべてのdefaultと制約は、[自動生成fieldリファレンス](./reference)で確認可能。

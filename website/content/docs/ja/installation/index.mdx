Rust executable と Python 解析 package の組合せ。workstation で必要な hardware transport のみを選択する構成。

## 前提環境

- stable Rust toolchain と Cargo
- `requirements.txt` 固定版 package を備えた Python 3
- direct GPIB または VISA 利用時のみの platform driver

```bash
python -m pip install -r requirements.txt
cargo install --path .
```

project 標準 hardware 一式を含む default build。hardware driver 不要の解析専用 install:

```bash
cargo install --path . --no-default-features
```

## 導入確認

```bash
pmoke --version
pmoke instruments list
pmoke config init --output config.toml
pmoke config validate --config config.toml
```

platform ごとの最小 build に向けた [feature 選択](./feature-flags)。
